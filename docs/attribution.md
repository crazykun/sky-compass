# 第三方素材与授权说明

本仓库为公开的教育科普项目，以下为使用的第三方素材及其授权情况。

## Astronomy Engine 2.1.19

- 用途：第一章「追光寻月」真实天文模式的月相角、照明比例、朔/上弦/望/下弦时刻计算。
- 作者：Don Cross，许可证：MIT。
- 以本地 vendored 方式存放于 `moonlight/assets/vendor/`，随附许可证文本 `moonlight/assets/vendor/LICENSE.astronomy-engine.txt`。

## 月面纹理（moonlight/assets/moon-texture.jpg）

- 用途：第一章「月面细节」模块的真实月面渲染。
- 来源：沿用原页面内嵌的 NASA 月面影像资源（历史迁移而来）。
- 授权：NASA 影像一般不受版权限制，使用规范参见 [NASA 影像与媒体使用指引](https://www.nasa.gov/nasa-brand-center/images-and-media/)。
- **待办**：该纹理经历史页面迁移而来，具体原始 URL 未留存；如需严格署名，发布前应确认其原始出处并补记于此。
