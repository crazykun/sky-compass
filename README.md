## 💛 这个站是怎么来的

我家有两个宝宝，老大刚上小学，正是仰望星空、满脑子"为什么"的年纪。

市面上的天文 App 太复杂，玩具望远镜又看不到几个月亮细节——于是我做了这个站：**打开网页，今晚的月亮长什么样、为什么长这样，孩子自己就能查、能拖、能玩**。每个互动都尽量让孩子"动手碰一碰"，而不是隔着屏幕听讲。

这个站最先的两位小用户，就是我家的两位小探险家。现在它也欢迎你家的。🔭

## 🧒 写给小探险家

嘿，小探险家！👋

今晚的月亮，是圆圆的盘子，还是弯弯的小船？

1. 打开 [第一章 · 追光寻月](https://sky.ailater.com/moonlight/)，页面上的大月亮就是**它今天的真实样子**——不是画的，是算出来的！
2. 找到「🌙 真实月相历」，点一点**今天的日子**，再点**你的生日**，看看那天的月亮。
3. 去「🪐 三体之舞」**拖一拖**太阳、地球和月亮，猜猜：月亮自己会发光吗？
4. 点页头的「🧒 小朋友模式」，月亮宝宝会给你讲故事、出题目考你哦！
5. 再去 [第二章 · 光的方向](https://sky.ailater.com/directions/) 跟着太阳转一圈：转动八方方位卡面向太阳，读出前后左右，最后闯一闯「辨向闯关」！

看完别忘了走到窗边，抬头找一找真正的月亮——**它就在那里，和页面上一模一样。**🌕

## 👨‍👩‍👧‍👦 给家长的陪伴指南

**睡前 5 分钟玩法（推荐）**

1. 🌙 睡前和孩子一起看页面上的「今天」，记住月亮的样子；
2. 🔮 让孩子**猜一猜**：明晚的月亮会变胖还是变瘦？
3. 🪟 第二天晚上先看窗外，再打开页面**对照答案**——猜对了会特别有成就感；
4. 🔁 坚持一个月，孩子会亲眼看到一整个「朔→望→朔」的循环，比背课文记得牢。

**两个模式，别讲混了**

- **真实天文**：由天文历表实时计算，就是今晚天上那个月亮，可以放心说"这就是真的"；
- **教学模拟**：把 29.53 天简化成 29.53 天的教学动画，用来理解原理，速度不是真实速度。

**快捷入口**（第一章支持查询参数）

| 参数 | 作用 |
|---|---|
| `?kid=1` | 直接进入儿童模式 |
| `?mode=sim` | 以教学模拟模式打开 |
| `?date=2024-09-18` | 查看指定日期（比如孩子生日、中秋节）的月相 |
| `?space=1` | 深空主题 |

**适龄建议**：5–7 岁走「小朋友模式」听故事；8–12 岁可以直接玩真实模式 + 三体模型；第二章的辨向闯关，正好在上学路上实地练习。📓

## ✨ 站点特色

- 🎯 **科学严谨**：真实模式由本地 Astronomy Engine 2.1.19 计算月相角、照明比例与朔望时刻，支持 1900–2100 年，农历换算与天文月龄分开处理，不糊弄"初八一定上弦"；
- 🖐️ **全互动**：日历、时间轴、三体模型、月面地标全部可拖可点，孩子不是在"看课件"；
- ⚡ **零构建、零 CDN**：纯静态站点，克隆即用，学校机房和老人机也能流畅打开；
- 🛡️ **为孩子做的细节**：尊重系统"减少动态效果"设置、后台标签页停止动画、键盘可访问、无任何账号与数据收集。

## 🚀 本地运行

纯静态站点，起一个 HTTP 服务即可（子页面用到 ES Module，请勿直接双击 HTML）：

```bash
python3 -I -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/
```
